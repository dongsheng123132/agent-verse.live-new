## 实现与验证

复用已有 Coinbase CDP facilitator，通过官方 `@x402/svm` 注册 Solana exact scheme。只有 facilitator 的 x402 v2 supported 中提供合法 feePayer 才报价 Solana；不支持或不可用时继续报价可用的 EVM 链。

单格、整块购买和 Key 找回都从 facilitator 已验证的交易中识别 USDC TransferChecked 的签名 authority。Solana 的格子 owner 不采用结算回执可能返回的手续费赞助方。地址比较保持 Solana 大小写；EVM 继续忽略大小写。

第一版仅支持标准钱包的一笔直接 SPL Token USDC TransferChecked。无法明确识别所有权的 CPI / lookup-table / 多笔匹配转账在结算前拒绝。没有数据库迁移：owner、payer、treasury 地址列均为 TEXT。

购买提示词、skill.md、API 信息、界面和更新记录已同步。`X402_NETWORK_MODE=testnet` 保持原有 Monad testnet / Base Sepolia；开发假结算开关原有三重保护保留。
